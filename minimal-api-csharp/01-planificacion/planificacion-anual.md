# Planificación anual

## Desarrollo de APIs con C# .NET 6 (Minimal API)

### Datos generales

| Campo | Detalle |
|---|---|
| Asignatura (denominación formal) | Desarrollo de APIs con C# .NET 6 (Minimal API) |
| Nivel y modalidad | Nivel secundario, modalidad técnica |
| Régimen | Curso anual |
| Carga horaria | 36 encuentros de 4 horas teóricas cada uno, 144 horas teóricas anuales (18 encuentros por cuatrimestre) |
| Entorno de trabajo | Visual Studio Code, terminal y SDK de .NET 6 |
| Acceso a datos | SQLite (hospital.db) mediante Dapper |
| Gestión de entregas | Repositorio único de GitHub por grupo, con carpetas tp-u1, tp-u2, tp-u3 y trabajo-final |
| Uso del celular | No permitido en ningún encuentro de la asignatura |

### Presentación

La asignatura propone un primer acercamiento al desarrollo de APIs con C# y .NET 6 mediante el enfoque Minimal API. El recorrido parte de un conocimiento nulo del lenguaje: se trabaja sin abstracciones intermedias (sin patrón repositorio ni inyección de dependencias) y con la totalidad del código en el archivo Program.cs, sobre el entorno Visual Studio Code y terminal. El control de versiones con Git y GitHub se encuentra entre los primeros contenidos de la asignatura y se constituye en un saber transversal que acompaña el trabajo de todo el año; el formato JSON se aborda de manera explícita antes de su uso en las respuestas de la API. El acceso a datos se resuelve con SQLite y Dapper sobre una base hospitalaria real (hospital.db) y las entregas se canalizan mediante un único repositorio de GitHub por grupo, cuyo flujo se profesionaliza de manera progresiva a lo largo del año.

### Sistema de evaluación

Cada unidad didáctica cierra con un encuentro dedicado (encuentros 9, 15, 26 y 32) con entrega por GitHub y defensa individual, y el encuentro siguiente abre con la devolución. Las instancias integradoras se califican con rúbrica de 100 puntos y las instancias de recuperación informan un resultado aún provisorio de Apto o No apto.
